## ❓ คำถามที่พบบ่อย | FAQ

### ถ: จำเป็นต้องใช้ Root หรือไม่?
ตอบ: ไม่จำเป็น แอปนี้ทำงานได้อย่างสมบูรณ์บนอุปกรณ์ที่ไม่ได้ Root โดยใช้ระบบ mock location API

### ถ: รองรับ Android เวอร์ชันไหนบ้าง?
ตอบ: รองรับ Android ทุกเวอร์ชันตั้งแต่ 4.4 จนถึง Android 14 ล่าสุดอย่างสมบูรณ์

### ถ: แอปอื่นสามารถตรวจจับได้หรือไม่?
ตอบ: ใช้เทคโนโลยี hook ขั้นสูงทำให้การตรวจจับเป็นเรื่องยากมาก แต่ควรใช้อย่างมีความรับผิดชอบ

### ถ: มีผลกระทบต่อแอปพลิเคชันอื่นหรือไม่?
ตอบ: มีผลเฉพาะฟังก์ชันที่เกี่ยวข้องกับตำแหน่ง ฟังก์ชันอื่นๆ ของแอปไม่ได้รับผลกระทบ
